Duplicate content: what actually causes it

Nobody sets out to duplicate content. It arrives through URL parameters, filters and a forgotten staging site.

Media Puppies · 16 September 2026 · Updated 15 October 2026

Duplicate content carries no penalty, not in the way people imagine. What happens is subtler and still costly: your signals split across several URLs, and Google picks one version — often not the one you'd choose.

Where duplicate content comes from

  1. Multiple URL versions. http and https, www and non-www, with and without trailing slash. Pick one, redirect the rest.
  2. Filter and sort parameters. Faceted navigation can generate hundreds of near-identical URLs.
  3. Manufacturer product descriptions. Five stores with identical text. Google keeps one.
  4. Location pages templated with a swapped city name. Not just duplicate — a doorway pattern that can hurt the whole site.
  5. A staging site left indexable. An entire second copy of your website competing with you.
  6. Case-sensitive URLs. /seo-services/ and /seo/ are different URLs on most hosting.

Duplicate content rarely gets you punished. It gets you ignored, which costs the same.

The fixes

  • Self-referencing canonical on every page.
  • Canonical filtered URLs back to the main category — except filter combinations with genuine search demand, which deserve their own indexable page.
  • 301 redirect the non-preferred protocol and hostname.
  • Block staging with authentication, not just robots.txt.
  • Write your own product copy. Reviews on the page help too — unique text that updates itself.

How to find it

Search site:yourdomain.com and look for the same page appearing several times. Then check Search Console's indexing report for Duplicate exclusion reasons, which names the URL Google chose instead.

How to find it on your own site in ten minutes

  1. Search site:yourdomain.com in Google. Skim the result count. If a twenty-page site shows four hundred results, parameters or filters are generating URLs you never intended.
  2. Open Search Console, Pages report. Look for "Duplicate without user-selected canonical" and "Alternate page with proper canonical tag". The first is a problem, the second is the system working.
  3. Request every variant by hand. Try the http version, the www version, the trailing-slash version and an uppercase version of one URL. Each should end in a single 301 to the one true address, not a 200.
  4. Take one distinctive sentence from a product page and search it in quotes. If a dozen other sites return the same sentence, that page has no original content on it.

The variant that catches everyone

Almost every site we audit serves its homepage on at least two URLs: / and /index.html. Both return 200, both render identically, and most owners have no idea the second one exists. On its own it is harmless — a self-referencing canonical resolves it. It stops being harmless when something links to the second version, because then you have two addresses accumulating separate authority for the same page.

The same thing happens with tracking parameters. A campaign URL ending in ?utm_source=facebook is technically a different page. Canonical tags handle this correctly, which is exactly why a missing canonical on a landing page you advertise is more expensive than a missing canonical anywhere else.

When duplication is the right answer

Not every repeat is a mistake. Shipping policy, return terms, warranty text and contact details are supposed to be identical across pages, and no amount of rewriting improves them. Manufacturer specification tables are the same — nobody wants a creatively reworded dimension.

The test is whether the duplicated block is the reason the page exists. A product page whose only content is the manufacturer's description has nothing of its own. The same description sitting beneath four paragraphs of your own sizing advice and photographs is fine.

Questions people ask

Is there a duplicate content penalty?

No. There is no manual action for ordinary duplication. What happens instead is that your signals split across several URLs and Google picks one to show, often not the version you would have chosen, and the rest earn nothing.

What causes duplicate content most often?

The same page reachable with and without a trailing slash, with and without www, over http and https, with tracking parameters attached, and through both a category path and a direct path. Printer views and paginated archives add more.

How do I fix it?

Put a self-referencing canonical on every page, redirect the variants to one chosen form, and make sure internal links all point at that form. For parameters, canonicalise to the clean URL rather than trying to block them in robots.txt.

Is duplicated product copy a problem?

Manufacturer descriptions repeated across hundreds of retailers rarely rank for anyone. It is not a penalty, it just means nothing on the page is yours. A few original lines of specification or use per product is usually enough to separate you.
