Three steps, about twenty minutes. Nothing here works until they're done.

  1. Create a free project at supabase.com.
  2. Open SQL Editor → New query, paste everything from supabase-schema.sql in the repo, and Run. This creates the leads table and locks it down.
  3. Open Project Settings → API, copy the Project URL and the anon public key into assets/js/supabase-config.js, then push.

Never paste the service_role key. It bypasses every security rule. Only the anon public key belongs in the site.

Finally, add yourself as a user: Supabase → Authentication → Users → Add user. That email and password is your login here.
